# Реалистичный календарь ВХЛ

## Первая версия

- Регулярный чемпионат сохраняет формат double round-robin: каждый клуб встречается с каждым дважды, дома и в гостях.
- Для каждой команды формируются домашние и выездные серии: целевой блок — около трёх матчей; допустимая максимальная серия — четыре матча.
- Число домашних и выездных матчей сбалансировано: разница не превышает двух игр.
- Игровые дни распределяются с интервалами 3–4 дня; старт сезона — 5 сентября.
- В расписании предусмотрена новогодняя пауза до 5 января.
- Для сезона 2026/27 при 30 клубах календарь из 58 игровых дней заканчивается в марте.
- Календарный экран группирует матчи по месяцам, показывает дату, площадку, результат и подпись домашней/выездной серии.

## Совместимость с сохранениями

- Добавлено поле `scheduleMeta` с датой каждого игрового дня.
- Добавлено поле `scheduleVersion: 2`.
- При загрузке старого сохранения сыгранные туры и пары соперников не меняются.
- Для будущих матчей старого сохранения допускается изменить только хозяев/гостей, чтобы сформировать серии и сохранить баланс площадок.
- Для следующего сезона полностью генерируется новое расписание версии 2.
- Молодёжные лиги используют тот же генератор домашних/выездных серий; календарные даты для них пока не выводятся.

## Ограничения первой версии / следующий этап

- Все клубы основной лиги пока играют в общие игровые дни; интервалы между ними одинаковы для всех команд.
- Пока не учитываются реальные расстояния между городами, последовательность географически соседних выездов, индивидуальные дни отдыха и отдельные переносы матчей.
- Следующий этап — staggered game days (разные даты для разных пар команд), географическая группировка выездных серий и влияние поездок на усталость/восстановление.
- Даты являются внутриигровым календарём, а не копией официального расписания ВХЛ.
