# Связи молодёжных команд с клубами ВХЛ

## Омские Ястребы — Омские Крылья

Официальная Академия «Авангард» описывает «Омских Ястребов» (МХЛ) и «Омские Крылья» (ВХЛ) как команды, базирующиеся в единой академической вертикали клуба. ВХЛ при запуске «Омских Крыльев» отдельно называла их фарм-клубом «Авангарда», который должен был обеспечить переход молодых игроков из МХЛ во взрослый хоккей.

Источники:
- https://academy.hawk.ru/ob-akademii/
- https://www.vhlru.ru/lenta/419193/
- https://mhl.hawk.ru/about/

## Игровая модель

В `data/youth-clubs.js` команда `mhl-omsk-hawks` сохраняет организацию `org-avangard` и официальную основную связь с «Авангардом» (КХЛ). Для игровой вертикали ВХЛ добавлено поле `seniorTeamSlug: 'omskie-krylya'`.

Это разделяет два понятия:
- `senior` — официальные/организационные связи и партнёры;
- `seniorTeamSlug` — конкретный взрослый клуб ВХЛ, с которым в игре работает механизм собственной молодёжной команды.

В `engine/youth-leagues.js`:
- создание молодёжной команды сохраняет `seniorTeamSlug`;
- поиск собственной молодёжной команды и бесплатный переход игрока проверяют эту явную привязку;
- существующие сохранения получают новое поле при нормализации;
- старые связи без `seniorTeamSlug`, включая МХК «Рязань-ВДВ» → «Рязань-ВДВ», продолжают работать по прежнему первому элементу `seniorLinks`.

«Авангард» (КХЛ) не получает вторую игровую привязку к той же молодёжной команде: в текущей игре взрослый управляемый клуб этой вертикали — «Омские Крылья» (ВХЛ).

Проверка: `tests/youth-system-links.test.js` — связь «Омские Крылья» → «Омские Ястребы», отсутствие дублирующей привязки к «Авангарду», обратная совместимость Рязани и миграция существующего сохранения.
