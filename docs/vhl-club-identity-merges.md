# Объединение исторических идентификаторов клубов ВХЛ

Дата обновления: 12 ноября 2026 года.

## Принцип

Сезонные результаты не переписываются: в каждой строке `historicalId` и `clubName` остаются такими, какими они были в исходном архиве. В справочнике несколько исходных идентификаторов объединяются в одну карточку, если подтверждена преемственность клуба, переименование или переезд одной команды. Все исходные ID сохраняются в массиве `historicalIds`.

## Другие проверенные названия

Следующие варианты уже находятся в одной карточке справочника и не требовали дополнительного объединения:

- «Горняк» / «Горняк-УГМК»: одна команда, переехавшая из Учалов в Верхнюю Пышму в 2021 году.
- «КРС-ОЭРДЖИ» / «ОЭРДЖИ»: одна команда, ставшая самостоятельной перед сезоном 2019/20.
- «Норильск» / «ХК Норильск»: варианты названия одной команды, основанной в 2023 году.
- «Тамбов» / «ХК Тамбов»: варианты названия одной команды из Тамбова.
- «Кристалл» / «Кристалл Саратов»: один саратовский клуб.
- «Металлург» / «Металлург Нк»: один клуб из Новокузнецка.
- «Ценг Тоу» / «Чэн Тоу» / «Цэнг Тоу»: варианты транслитерации одного китайского клуба.

## Что намеренно не объединялось

- «Динамо СПб» — отдельный клуб, не смешивается с фарм-командой московского «Динамо».
- «Звезда-ВДВ» — отдельная команда, не смешивается с клубом ЦСКА «Звезда».
- «КРС-БСУ» и «КРС-Хэйлунцзян» — отдельные китайские команды, не смешиваются с «ОЭРДЖИ».
- «Горняк» (Учалы/Верхняя Пышма) не смешивается с другими одноимёнными командами вне этой клубной линии.
- «Торпедо-Горький» (Нижний Новгород) не смешивается с усть-каменогорским «Торпедо».

## Пропуск сезонов «Лады»

В архиве ВХЛ у «Лады» есть сезоны 2010/11–2013/14 и 2018/19–2022/23. В сезонах 2014/15–2017/18 клуб выступал в КХЛ, поэтому отсутствие строк ВХЛ — не ошибка и не прекращение существования клуба. С сезона 2023/24 «Лада» вновь играет в КХЛ. Фиктивные строки ВХЛ не добавляются.

## Контроль целостности

- 56 карточек справочника.
- 435 сезонных записей сохранено.
- 74 исходных historicalId сохранены ровно по одному разу.
- Внутри каждой карточки нет повторяющихся сезонов.
- Исторические названия в сезонных строках не заменяются названием карточки.
