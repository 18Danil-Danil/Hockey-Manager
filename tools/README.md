# Импорт и синхронизация составов ВХЛ

## Автоматическая синхронизация через GitHub Actions

В репозитории настроен workflow **«Синхронизация составов ВХЛ»**.

- Запуск по push в ветку `refactoring` — автоматический.
- Запланированный запуск — еженедельно по понедельникам в 04:17 UTC. GitHub выполняет расписание только для workflow, находящегося в default branch; пока workflow существует только в `refactoring`, расписание не активно.
- Ручной запуск через `workflow_dispatch` поддерживается после появления workflow в default branch. До этого можно проверять запуск по push в `refactoring`.
- По умолчанию инструмент обрабатывает все клубы ВХЛ, сопоставляя каталог ВХЛ с 30 клубами игры.
- Можно выбрать отдельный клуб по slug, например `ryazan-vdv`.
- Перед запросами проверяется `robots.txt`; если его нельзя прочитать или он запрещает раздел команд, выгрузка останавливается.
- Между запросами страниц клубов выдерживается пауза.
- Результат и отчёт сохраняются в GitHub Actions Artifact на 14 дней. JSON не коммитится в публичную ветку автоматически.

## Где найти результат

1. Открой вкладку **Actions** репозитория.
2. Выбери **Синхронизация составов ВХЛ**.
3. Открой последний запуск.
4. В блоке **Artifacts** скачай `vhl-rosters-...`.
5. Распакуй архив: внутри будут `vhl-rosters.json` и отчёт синхронизации.
6. В игре открой **Настройки → Реальные составы ВХЛ** и загрузи JSON. Он применяется к новым карьерам; существующие сохранения не изменяются.

## Локальный запуск

Node.js 20+:

```bash
node tools/vhl-roster-sync.mjs --team all
node tools/vhl-roster-sync.mjs --team ryazan-vdv
```

Старый одно-клубный экспортёр также сохранён:

```bash
node tools/vhl-roster-exporter.mjs 378 ryazan-vdv
```

## Ограничения и ответственность

- Экспортёр получает только основной состав, не травмированных игроков, фотографии или статистику.
- ВХЛ может изменить HTML-разметку; при неполном составе команда отмечается ошибкой, а не добавляется как корректная.
- В JSON включаются ФИО, даты рождения, гражданство и номера игроков. Артефакт не публикуется в Git, но доступен пользователям с доступом к Actions в репозитории.
- Ссылка на источник не равна лицензии. Перед распространением или публичным использованием базы нужно проверить условия ВХЛ и правовые основания обработки персональных данных.
