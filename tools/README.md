# Импорт составов ВХЛ

## Прототип: Рязань-ВДВ

Для выгрузки одного текущего состава требуется Node.js 18 или новее. Из корня репозитория выполни:

```bash
node tools/vhl-roster-exporter.mjs 378 ryazan-vdv
```

Инструмент запросит одну страницу официального сайта ВХЛ и создаст файл:

`vhl-ryazan-vdv-roster.json`

Далее:
1. Открой Hockey Manager.
2. Перейди в **Настройки → Реальные составы ВХЛ**.
3. Выбери созданный JSON.
4. Начни новую карьеру.

Для клуба «Рязань-ВДВ» будут использованы импортированные имена, амплуа, номера, даты рождения и гражданство. Игровые характеристики, потенциал и контракты пока рассчитываются игровым генератором. Остальные клубы продолжат использовать вымышленные составы, пока для них не будет подготовлен импорт.

## Ограничения прототипа

- Импорт не меняет уже начатые карьеры.
- Данные хранятся локально в браузере пользователя.
- Фотографии и статистика не импортируются.
- Экспортёр рассчитан на одну страницу клуба за запуск и намеренно останавливается, если не распознаёт минимум 20 игроков.
- Структура HTML сайта может измениться; в таком случае экспорт завершится ошибкой, а не создаст заведомо неполный файл.
- Перед публичным распространением базы необходимо получить разрешение ВХЛ на автоматизированное получение, хранение и отображение данных. Указание ссылки на источник само по себе не является такой лицензией.
